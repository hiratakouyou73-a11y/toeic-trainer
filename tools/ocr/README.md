# ローカル OCR 単語抽出ツール（Phase 6）

書籍（『金のフレーズ』など）のページ画像から、Windows 11 標準の OCR エンジンを用いて単語・日本語訳・品詞を抽出し、**下書きCSV** を自動生成するツールです。

* **外部送信ゼロ**: クラウド等の外部サービスには一切接続せず、PC内だけで高速に画像認識を行います。
* **安全性**: 生成されるCSVは下書き（`checked` 列が空欄）です。人間が確認して `checked=1` を入力した単語だけがアプリに読み込まれます。

---

## 1. 使い方

### ステップ①：書籍ページを撮影・配置する
1. スマホのカメラ等で書籍のページを撮影します。
2. 撮影した画像（`.jpg` または `.png`）を、以下のフォルダにコピーします。
   * **画像配置先**: `C:\Users\hirat\toeic-private\images\`
   * ※ファイル名を `kin_p001.jpg`, `kin_p002.jpg` のようにしておくと管理しやすいです。

### ステップ②：OCR抽出スクリプトを実行する
PowerShell を開き、以下のコマンドを実行します。

```powershell
cd c:\Users\hirat\AI-Brain\toeic-trainer
powershell -ExecutionPolicy Bypass -File tools/ocr/extract_words.ps1 -Prefix "kin"
```
* `-Prefix` には単語IDの接頭辞（例: `kin` → `kin-0001`）を指定できます（省略時は `kin`）。

### ステップ③：下書きCSVを確認・修正する
実行が完了すると、以下のフォルダに日時のついた下書きCSVが生成されます。
* **出力先**: `C:\Users\hirat\toeic-private\ocr_drafts\draft_kin_YYYYMMDD_HHMMSS.csv`

1. 生成されたCSVを **Excel** で開きます（BOM付きUTF-8のため文字化けしません）。
2. `word`（英単語）や `meaning`（日本語訳）の誤認識・ズレがないか確認し、必要に応じて修正します。
3. **アプリに登録したい行の `checked` 列に `1` を入力します。**
   * （誤認識した行や不要な行は `checked` を空欄のままにしておけば、アプリ側で自動スキップされます）
4. 名前を付けて `C:\Users\hirat\toeic-private\csv\kin_unit1.csv` 等として保存します（Excelで保存時は「CSV UTF-8」または「CSV（コンマ区切り）」を選択）。

### ステップ④：スマホのアプリで読み込む
1. 完成したCSVファイルを USB 等でスマホにコピーします。
2. スマホの TOEIC Trainer を開き、「⚙️ 設定」→「教材CSVを読み込む」からファイルを選択します。
3. `checked` 列が `1` の確認済み単語だけが安全に取り込まれ、ホーム画面から学習できるようになります。

## 2. きれいに認識させる撮影のコツ
* **真上から撮影する**: ページに対して斜めから撮ると文字が歪み、誤認識の原因になります。
* **明るい場所で、影を落とさない**: スマホ自身の影がページにかからないよう、斜め上からの照明や自然光を活用してください。
* **本を平らに押さえる**: ノド側（本の綴じ目付近）が湾曲していると端の単語が読みにくくなるため、手や定規等で軽く押さえて撮影してください。
